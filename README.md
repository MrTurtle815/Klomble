# **About**
Klomble is a open-source physics engine that aims at teaching people physics through engaging simulations, customizable properties, and much more! Our goal is to teach people physics in a fun way that anyone can understand. Klomble is also open-source which allows anyone to learn how things work under the hood! Though I will say that Klomble is not finished nor production ready just yet! Though I hope by the end of December 2026 I can release V1.0!

# **License**
I chose the General Public License (GPL) for this project as I would like to allow people to learn from Klomble's code and to see how everything works under the hood! Though I also wanted to see all the contributions and improvements that other people have made and be able to credit them for their ideas, so I though the GPL would fit the best! Feel free to fork this repository and add your improvements!
